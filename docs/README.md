## 실행
압축을 푼 뒤 HTML 파일을 Chrome, Edge, Safari 등 최신 브라우저에서 엽니다. 별도 패키지 설치 없이 모바일/데스크톱 브라우저에서 동작합니다.

## 주요 메뉴
1. 홈
2. 비식별화 작업(텍스트 입력 / TXT·CSV 파일 선택)
3. 탐지 및 처리 결과
4. 설정·안내

## 기존 저장소 기능 연결 관계
- `pii_tool.detect.find` → 개인정보 탐지 및 유형별 건수
- `pii_tool.detect.PATTERNS`, `LABEL` → 지원 유형 및 화면 레이블
- `pii_tool.mask.anonymize` → 비식별화 처리 개념
- `pii_tool.mask.replacement` → mask/token/hash/redact 방식
- `pii_tool.cli.main` → scan/run 입력·출력 흐름
- `--csv` → CSV 셀 단위 처리 옵션

## 구현 범위 및 주의
이 HTML은 모바일 메뉴 이동, 텍스트 입력, TXT/CSV 파일 읽기, 탐지 시뮬레이션, 4가지 치환 방식, 결과 복사 및 다운로드를 포함한 프론트엔드 컨셉 시안입니다. 기존 Python 엔진이나 REST API와 직접 연결되어 있지 않으며, 브라우저 내 구현은 운영 엔진과 완전히 동일한 검증 로직이 아닙니다. 특히 사업자번호 검증, 주민번호 체크섬, CSV 구조 처리 등은 운영 엔진과 동등성 테스트가 필요합니다.

자동 탐지는 일부 유형만 지원하며 누락/오탐이 발생할 수 있습니다. 계좌번호, 여권·운전면허번호, 외국 형식, 라벨 없는 이름, 자유 형식 주소 등은 탐지하지 못할 수 있습니다. 공유 전 반드시 사람이 결과를 확인해야 합니다.
